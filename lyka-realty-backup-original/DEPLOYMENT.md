# Deployment guide (Render + PostgreSQL)

## What the included blueprint does

`render.yaml` describes a Python/FastAPI API service, a separate static React site, and a managed PostgreSQL database. It does not deploy the local SQLite file or copy local customer/account records into production. The CSV inventory is imported separately. The blueprint assumes the service URLs `https://lyka-realty-ai.onrender.com` and `https://lyka-realty-web.onrender.com`; if Render assigns different URLs, update `VITE_API_URL` and `CORS_ORIGINS` in the service environment before using the app. Choose a hosting/database plan suitable for your expected traffic and budget; managed PostgreSQL may incur a charge.

## Before deploying

1. Rotate the OpenAI key, Gemini key, and JWT secret that were present in the original uploaded `backend/.env` file. Do not reuse those values.
2. Push this cleaned project to a private Git repository. Ensure `backend/.env`, databases, backups, `.venv`, `node_modules`, and build output are not committed.
3. Create a Render Blueprint from the repository and review the service/database plan and estimated cost before confirming.
4. In the API web service environment, set `GEMINI_API_KEY` and `OPENAI_API_KEY` to newly generated keys if you have both. The Render blueprint uses Gemini (`AI_PROVIDER=gemini`) and can fall back to OpenAI if the OpenAI key is configured. Local Ollama is recommended only for local development; a Render web service cannot reach Ollama on your personal computer. You can reverse the preference with `AI_PROVIDER=openai`. Configure model names that are available to your accounts. At least one valid provider key is required; failover requires both.
5. `JWT_SECRET` is generated by Render through the blueprint. Do not replace it with a predictable string.

## Import the real rental inventory

After the API service and PostgreSQL database are available, open the API web service's Shell and run:

```bash
cd backend
python scripts/import_properties.py --csv ../dubai_properties.csv
```

Run this against the production database only after confirming the `DATABASE_URL` points to the intended database. The importer is designed to update matching source listings and insert additional rows; inspect the reported counts. Do not repeatedly run it against a database that has been manually edited without first taking a backup.

## Create the first production administrator

The local SQLite users/leads/visits are **not automatically migrated** into PostgreSQL. After deployment, open the API web service Shell and run:

```bash
cd backend
python create_admin.py
```

Use an authorized company administrator email and a unique strong password when prompted. Never paste credentials into chat or commit them to source control. Then log in and create/activate employee accounts from the admin screen.

## Post-deployment checks

- Open `https://lyka-realty-ai.onrender.com/api/health` (or your actual API host) and confirm `status=online`, `database=connected`, and `database_type=postgresql`.
- Open `https://lyka-realty-ai.onrender.com/docs` (or your actual API host) and test `/api/auth/register`, `/api/auth/login`, `/api/properties/search`, and `/api/ai/chat` with a real authorized account.
- Search for an actual listing from the imported CSV and confirm the listing's purpose and annual rent are correct.
- Test Tamil, Tanglish, and English. Browser speech recognition/synthesis varies by browser and installed voices; server-generated speech currently requires an OpenAI API key. Test microphone and audio on the target device before launch.
- Test provider failover by temporarily using an invalid key only in a local development environment; never intentionally break production credentials. Confirm logs show fallback without revealing keys.
- Test role boundaries using separate customer, employee, and admin accounts. Do not use the production admin account for normal customer testing.

## Important limitations before public launch

- The current voice feature uses browser speech recognition and speech synthesis, with optional backend OpenAI text-to-speech. It is not a full-duplex OpenAI Realtime voice session.
- Arabic-ready UI and multilingual model prompting do not by themselves guarantee Arabic speech recognition or speech synthesis on every browser.
- The CSV is rental-only. Do not advertise sale prices, property-specific images, amenities, or investment yields unless independently verified data is added.
- Before production traffic, configure backups, monitoring, rate limiting, a privacy notice, and an authorized process for handling customer data.
